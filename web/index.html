GET STARTED
从配置到答题。
无需安装 npm 依赖，也无需手工编辑 JSON。
首次使用
  1. 双击 start.cmd，控制台会自动在浏览器打开。
  2. 在“接口与模型”添加服务商，填写完整接口地址、模型 ID 和 Key，保存配置。
  3. 在“答题策略”为文字题和图片题选择接口；同一条路由的多个接口按顺序作为备选。
  4. 到“在线试答”测试一次文字题；视觉模型可上传图片单独验证。
  5. 到“连接 OCS”选择模式，复制或下载配置导入 OCS。
接口怎么填
DeepSeek 使用 https://api.deepseek.com/chat/completions。OpenAI 使用 https://api.openai.com/v1/chat/completions。Claude 使用 https://api.anthropic.com/v1/messages。第三方平台填写它提供的完整地址和准确模型 ID。
API 格式选择“Chat Completions”或“Claude Messages”。图片能力必须与具体模型一致；纯文字模型不应开启图片能力。
省 Token 模式
按题型发送短提示词，选择 / 判断默认最多 32 Token，填空 / 简答默认最多 512 Token。默认每个接口只尝试一次，不生成长 JSON 答案对象。DeepSeek 省 Token 配置会关闭深度思考；其他模型可通过“省 Token 专用参数”按该模型文档设置。
日常启动与升级
以后直接双击 start.cmd。重复启动会优先打开已有的同版实例；端口被其他程序占用时会提示并选择空闲端口。diagnose.cmd 检查运行环境，不会调用付费模型。
升级时保留原来的 .env 和 config.json，用新版程序文件覆盖旧版，再重新运行 start.cmd。切换端口后重新导入 OCS 配置。
常见问题
401：本机 token 错误时重新下载 OCS 配置；模型鉴权错误会明确显示对应服务商失败。管理页的“查询模型列表”与“试答”可帮助区分问题。
图片不可读：开启 OCS 图片题优化，选择有视觉能力的模型。图片过大、格式不支持或缺失时会显示原因。
答案被截断：在答题策略提高对应输出上限，或改用完整模式。上限不是固定收费量。
Token 统计：只统计供应商实际报告的用量；没有上报时显示“未上报”，不把估算当作真实用量。控制台记录在本次进程中保留，重启后清空。
