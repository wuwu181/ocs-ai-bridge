# V3：题库、设备共享与费用

## 更新到 V3

安装 Node.js **22.13+，推荐24 LTS**。SQLite 使用 Node.js 内置模块，无需 npm install。停止旧服务窗口后，用新版程序覆盖旧程序，保留自己的 `.env`、`config.json`；已有 V3 用户还应保留 `data/`。重新运行 `start.cmd`，从“连接 OCS”重新导入配置。

已有配置无需手工增加新字段，程序会补默认值。首次在页面保存后，新设置才写入配置文件。不要直接复制别人的 `.env` 或数据库，设备令牌的加密依赖本机管理令牌。

## 截图问题和基础参数

- 判断题返回 A/B：只有原始两个选项明确分别表示“对/错”时才按选项顺序映射，支持“错误、正确”的反向顺序。缺少明确映射时，省 Token 模式允许一次完整格式修正；修正仍失败则返回错误，避免猜测。
- 第二张截图的 32 / 512 / 1次 / 并发2 均有效。32 是选择和判断的输出上限，512 是省 Token 填空与解答的上限；1次是每个候选模型的默认尝试次数，判断格式修复是例外。并发2控制服务同时执行的 AI 请求，设备还有独立并发限额。
- 隐藏推理也可能占输出预算。遇到截断时提高模型专用上限或使用完整模式，不应直接把截断内容当答案。
- “在线试答”默认绕过题库和内存缓存，便于检测模型；勾选“试答也优先查自建题库”后才使用题库。正常 OCS 答题默认先查库。

## 本地模型

本版通过 OpenAI Chat Completions 兼容接口连接本地模型。在“接口与模型”添加接口，选择 Ollama 或 LM Studio 预设。先在本地模型软件中启动模型服务。

| 软件 | 完整地址 | 配置 |
| --- | --- | --- |
| Ollama | `http://127.0.0.1:11434/v1/chat/completions` | 无鉴权；填写已下载模型的准确名称 |
| LM Studio | `http://127.0.0.1:1234/v1/chat/completions` | 使用软件中实际监听端口；按是否开启认证选择鉴权 |
| vLLM / llama.cpp 等 | 该服务提供的 `/v1/chat/completions` 完整地址 | 填写该服务公布的模型 ID |

如果模型在路由器下的另一台机器上，把地址中的 `127.0.0.1` 改为那台模型服务器的局域网 IP。桥接服务和模型服务的监听设置各自独立。不要将无鉴权模型服务直接开放到公网。

保存接口后把它加入文字路由，需要识图时再加入图片路由；具体模型必须支持视觉。部分本地模型不支持 JSON Mode，可保持关闭。慢模型应降低并发；OCS 单次请求有约60秒的总时限，本版默认50秒预算。

纯本地运行没有服务商 Token 账单时，可在“费用与统计 → 各接口自定义价格”中配置：

```json
{"ollama":{"input":0,"cached":0,"output":0,"peakMultiplier":1}}
```

这里 `ollama` 必须换成自己的接口标识，0元仅表示 API Token 价格，不计算电脑电费和硬件成本。

## 同一路由器下的其他设备

1. 在“网络与共享”把监听地址改为 `0.0.0.0`，点击应用，然后顶部保存配置。
2. 停止服务并重新运行 `start.cmd`。
3. 查看页面列出的局域网地址候选，例如 `http://192.168.1.20:8765`。多网卡、虚拟网卡或 VPN 可能列出多个地址，应选择目标设备可达的那个。
4. 在系统防火墙允许这台电脑的服务端口通过所需网络。可将该电脑在路由器中设置 DHCP 地址保留，减少 IP 变化。
5. 在“设备与限额”为手机、平板或另一台电脑分别创建设备。
6. 到“连接 OCS”，选择该设备，将服务根地址填为上面的局域网地址，下载 JSON，在对应设备的 OCS 中导入。

`0.0.0.0` 是监听地址，不能作为其他设备的访问地址；它们的 `127.0.0.1` 也指向各自设备。AP隔离、访客Wi-Fi、不同VLAN或防火墙规则可能阻止互访，需要在路由器中按你的网络实际情况放行。

## 自己的公网 / 域名

本项目支持自有服务器或自有 HTTPS 反向代理入口，没有内置穿透套餐或自动修改路由器功能。

- 有公网IP时，可使用路由器端口转发到运行桥接服务的主机，或在自有服务器部署；建议使用自己的域名和 HTTPS 入口。
- 处于运营商 NAT 后时，普通端口转发不能使服务从公网可达，需要你已有的可达服务器、VPN或穿透入口。
- 在“网络与共享”记录公网根地址，例如 `https://ai.example.com`。这不会创建域名或自动安装证书；导出时仍以“连接 OCS”当前填入的根地址为准。
- 在“连接 OCS”选择独立设备、填写公网根地址，导出的请求将指向该地址。公网和局域网导出均要求使用设备令牌，避免把管理令牌分发给其他人。
- 反向代理必须保留 `Host`，超时建议至少60秒，请求体上限至少与图片总量匹配。管理页面依赖同源校验。

自己使用 Nginx 时，可参考下面的 `location`，放入你已配置 HTTPS 的 server 块，并调整桥接服务地址：

```nginx
location / {
    proxy_pass http://127.0.0.1:8765;
    proxy_set_header Host $http_host;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_read_timeout 65s;
    client_max_body_size 32m;
}
```

如不希望公网访问后台，可只代理 `/api/` 与 `/health`，其余路径拒绝访问，管理通过本机或自己的 VPN 完成。实际设备配置仍使用同一服务根地址。

只有“可信反向代理 IP”中明确列出的 TCP 对端，才能让服务读取 X-Forwarded-For 的最右一项。应只填你控制的最后一层代理的准确IP；代理必须追加真实客户端地址。默认留空，忽略客户端伪造的转发头。多层代理下最右一项可能仍是另一层代理，统计应按实际链路理解。

## 设备限额和权限

每个设备具有独立随机令牌，服务端只保存它的哈希和加密副本。设备令牌可答题，不能读取管理配置、修改模型、查询题库后台或查看其他设备。停止设备后，旧配置也会立即失效；可重新启用恢复访问。

可设置每天请求数、每天 Token、每天预估人民币、每分钟请求数、设备并发数、允许IP（准确IPv4/IPv6或IPv4 CIDR网段）及允许模型标识。0 表示对应数量不限；并发至少为1。

多个客户端复制同一设备配置时，服务把它们视为同一设备，共享限额。设备身份来自令牌，不是浏览器指纹。IP统计来自服务能看到的地址；NAT 后的多个设备可能共享公网IP。

日限额按 **Asia/Shanghai** 零点重置，累计数据保存在SQLite，重启不会清空。请求次数在放行时计入，包括题库命中、失败和取消的已放行请求；校验前被拒绝的请求不计入。

Token和费用要等上游返回后才能结算，因此最后一笔请求可能超额。设备并发可减少同时超额，但这些限制不等同于严格预扣款。服务商不报告usage、网络中断或进程异常时，可能出现未知费用；已有未知费用且设置了费用限额的设备会停止后续调用，避免把未知计为免费。未完成请求跨重启标为未知。

## 自建题库与搜索

数据库：`data/workspace.sqlite`，SQLite WAL模式。**整份 data/ 都是本机数据，不进入Git或分发包。** 正常退出后备份整个目录；运行中直接只复制主文件可能遗漏WAL中的最新内容。

默认流程：精确题库 → 当前进程内存缓存 → 选择模型 → 验证答案 → 自动入库。题库命中不调用模型，新增Token和费用为0。自动保存的新答案是“AI待核对”，并不代表人工确认。可开启“只复用已核对答案”，人工核对后才用于自动回填。

精确查找使用SHA-256指纹唯一索引，指纹包含题型、规范化题干、选项顺序、空数和图片内容。不会因为关键词相似就自动返回答案，选项顺序改变也不会误用原字母。相同图片的地址变化可能造成未命中，这是保守处理。

页面搜索使用SQLite FTS5 trigram全文索引，支持中文；不足3个字符的短关键词使用子串查找。搜索结果分页，每页30题。搜索结果仅用于人工查看和编辑，不直接作为模糊匹配答案。

在“自建题库”可以新增、搜索、筛选、编辑、删除或停用记录，支持单选、多选、判断、填空和解答。编辑时可替换或移除图片。多空答案使用JSON字符串数组，代码解答保留正文、换行与特殊字符。删除、修改和停用记录会清空内存缓存，后续答题立即采用新记录。

AI再次回答同一题时不会覆盖已有人工修改的记录。需要重新获取答案时，可在在线试答中绕过题库，核对后手动修改原记录。

## 费用预估

使用[DeepSeek官方人民币价格页](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)，核对日2026-11-05。价格单位为每百万Token。

| 模型 | 空闲输入未命中 | 空闲输入命中 | 空闲输出 | 高峰倍率 |
| --- | ---: | ---: | ---: | ---: |
| deepseek-flash | ¥1 | ¥0.02 | ¥4 | 2 |
| deepseek-v4-pro | ¥4.5 | ¥0.15 | ¥13.5 | 2 |

按北京时间的工作日高峰窗口09:00–12:00、14:00–18:00选择倍率；午休、晚上、周末和假期使用空闲价格。每次模型调用按发起时间估价，跨时段请求和服务商的最终计价时点可能产生差异。重试和切换模型按各次实际返回的usage累计。

默认预置2026年假期，来源为[国务院办公厅放假安排](https://www.beijing.gov.cn/zhengce/zhengcefagui/202511/t20251104_4258873.html)。跨年需要手动更新假期列表。价格也应在服务商调整后手动更新。未设置工作日例外时，周末保持空闲费率。

只有官方 `api.deepseek.com` 的已知模型自动使用此价。第三方转发、其他模型和本地服务需要自行设置接口价格，不会因名称含“deepseek”就假定收费相同。模型返回缓存命中Token时分开计算；未给拆分则全部按未命中价格保守估算；没有usage的调用不显示为0元。

“费用与统计”可以按北京时间日期查询持久化请求、Token、题库命中、IP用量和估计人民币。价格变更只影响之后的调用，历史费用保留当时的估算。当前不包含真实支付、充值、发票或自动扣款功能，以服务商账单为准。

## 接口新增项

管理端点均使用管理员Bearer token，设备token不可访问：

| 端点 | 用途 |
| --- | --- |
| `GET /admin/network` | 地址候选与网络设置 |
| `GET/POST /admin/devices` | 设备列表、新增设备 |
| `PUT /admin/devices/{id}` | 编辑权限或停用设备 |
| `GET /admin/ocs-config?device={id}&base={根地址}&mode=auto` | 导出设备配置 |
| `GET /admin/questions?q={词}&kind={题型}&page=1` | 分页搜索题库 |
| `POST /admin/questions` | 新增记录 |
| `GET/PUT/DELETE /admin/questions/{id}` | 查看、修改、删除 |
| `GET /admin/analytics?day=2026-11-05` | 指定北京时间日期的统计 |

答题请求可加 `use_database:false` 强制绕过题库和内存缓存。人工保存记录的请求体示例：

```json
{
  "input":{"title":"1+1等于多少？","type":"single","options":["1","2","3"]},
  "answer":"B",
  "enabled":true,
  "reviewed":true
}
```

## 开源参考和验证

连接本地模型参考 [Ollama官方兼容接口](https://docs.ollama.com/api/openai-compatibility)与[Ollama仓库](https://github.com/ollama/ollama)；数据浏览方式参考[Datasette](https://github.com/simonw/datasette)；设备令牌和用量管理参考[One API](https://github.com/songquanpeng/one-api)的功能划分。中文检索采用[SQLite FTS5官方trigram方案](https://www.sqlite.org/fts5.html)。本版未复制这些项目源码，也不需要安装这些完整后台。

运行 `npm test` 集中验证。原有24项加V3的10项接口测试共34项；独立Edge验证10个后台流程。均使用模拟上游，没有用真实Key调用付费模型。真实模型准确率、用户路由器、公网可达性和服务商最终账单需要在自己的环境确认。
