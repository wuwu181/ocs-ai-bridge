# 快速上手

首次使用按下面五步操作。API Key 只保存在运行本项目的电脑上；仓库中的模板没有真实 Key。

## 1. 下载和准备

1. 安装 [Node.js](https://nodejs.org/)，版本至少 22.13（推荐24 LTS）。安装后在新终端执行 `node --version` 确认版本。
2. 从 [仓库](https://github.com/wuwu181/ocs-ai-bridge) 点击 **Code → Download ZIP**。私有仓库需使用有访问权限的账号登录。
3. 把整个 ZIP 解压到自己的目录，例如 `D:\Tools\ocs-ai-bridge`。不要在压缩包预览窗口里直接运行脚本。

也可以使用 Git：

```powershell
git clone https://github.com/wuwu181/ocs-ai-bridge.git
cd ocs-ai-bridge
```

无需安装第三方 npm 依赖。浏览器的 OCS 脚本需要另外安装并启用，本项目只提供模型答题接口和控制台。

## 2. 启动控制台

Windows 双击 `start.cmd`，或在目录中运行：

```powershell
.\start.cmd
```

首次启动自动生成本机配置和随机访问令牌，并打开控制台。默认地址 `http://127.0.0.1:8765/`；端口被占用时自动顺延，以窗口显示的地址为准。保持服务窗口运行。

手动打开页面需要登录时，在本机 `.env` 找到 `OCS_BRIDGE_TOKEN`，只把值粘贴到本机控制台登录框。它不是模型服务商的 API Key，不能用来请求 DeepSeek 或 OpenAI。

macOS / Linux 或不希望自动打开浏览器时：

```sh
node launcher.mjs --no-browser
```

## 3. 添加模型接口

进入左侧“接口与模型”，编辑预设或新增接口。必填信息：

| 字段 | 填写方式 |
| --- | --- |
| 协议 | OpenAI Chat Completions 或 Anthropic Messages，按平台文档选择 |
| 接口地址 | 完整请求地址，例如 `https://api.deepseek.com/chat/completions` |
| 模型 ID | 该账号可调用的准确模型名称；可尝试查询模型列表 |
| API Key | 从对应服务商控制台取得，只粘贴到本机页面 |
| 启用 | 打开该接口的启用开关 |
| 支持图片 | 仅在具体模型具备视觉能力时开启 |

先点击模型编辑框中的“应用到工作区”，再点击顶部“保存配置”。仅应用未保存，不会更新正在使用的接口。

常用完整地址：

- DeepSeek：`https://api.deepseek.com/chat/completions`
- OpenAI：`https://api.openai.com/v1/chat/completions`
- Claude：`https://api.anthropic.com/v1/messages`
- 第三方平台：使用平台提供的完整端点，不能只填根域名。

进入“答题策略”，把已配置接口加入“文字题”路由；需要图片时也加入“图片题”路由。默认路由指向 `deepseek`，新增其他接口后需要相应调整。保存设置。

Key 输入框留空表示保留已有值。需要移除旧 Key 时明确勾选清除选项。不要把 API Key 放进模型名称、截图、GitHub Issue 或题干里。

## 4. 先试一题

进入“在线试答”，选择已配置接口，模式选“省 Token”，题型选“单选”。

```text
题目：1+1等于多少？
选项（每行一个）：
1
2
3
4
```

提交后应返回 `B`。在线试答会真实调用服务商并产生相应用量。健康检查成功只表示本机接口正常，不能代替这一步检查模型权限和 Key。

需要图片时，改用“自动”或“完整”模式，上传清晰的题干图，选择支持图片的模型后试答。纯文字省 Token 接口不接受图片。

## 5. 导入 OCS

1. 打开本机控制台“连接 OCS”。
2. 选择模式：基础文字题选“省 Token”；需要文字与图片混合使用选“自动”；复杂解答和图片可选“完整”。
3. 通常保留自动路由；需要始终调用同一模型时，再指定固定接口。
4. 复制配置或下载 JSON。
5. 打开 OCS 的“通用 → 全局设置 → 题库配置”，粘贴导出的 JSON 并保存。不同版本菜单名称可能略有变化。
6. 同一用途通常只启用一份配置，避免多份题库同时调用模型。
7. 自动 / 完整模式打开 OCS“图片题优化”；纯文字省 Token 配置可关闭。

从普通练习题确认结果。若 Tampermonkey 提示访问本机地址的权限，允许脚本访问导出配置中的 `127.0.0.1` 地址。远程设备不能通过自己的 `127.0.0.1` 访问这台电脑。

导出配置包含本机访问令牌，虽然没有服务商 API Key，也应保留在自己设备上。

## 下次使用和更新

日常双击 `start.cmd` 即可，保存的模型与 Key 会继续使用。停止时在服务窗口按 `Ctrl+C`。

Git 安装可在停止服务后执行 `git pull --ff-only` 更新，再启动。ZIP 安装用新程序覆盖旧程序，保留本机 `.env` 和 `config.json`；更新后重新导出 OCS 配置。修改端口也需要重新导出。

遇到异常先运行 `diagnose.cmd`。更多配置见 [主说明](../README.md)，常见错误见 [故障排查](TROUBLESHOOTING.md)。

V3 的题库、设备导出、本地模型、局域网与公网连接及费用统计见 [V3指南](V3.md)。正常 OCS 请求默认先查本地题库；新增AI答案标为待核对。分享给其他设备时，在后台创建设备并导出它的独立配置。
